# ✨ Overview

**EventFlow** is a full-stack event booking platform designed to provide a smooth experience for discovering, creating, and booking events.

Users can create an account, browse available events, search events by location and date, check seat availability, make bookings, complete online payments through SSLCommerz, manage their profile, and upload a profile image.

The project was built to practice and demonstrate modern **frontend development, REST API integration, JWT authentication, database management, payment gateway integration, email workflows, cloud image storage, and full-stack deployment**.

# 🔐 Authentication Flow

EventFlow uses **JWT-based authentication**.

```text
┌──────────────┐
│    User      │
└──────┬───────┘
       │
       ▼
 Register / Login
       │
       ▼
┌──────────────┐
│ NestJS Auth  │
│   Service    │
└──────┬───────┘
       │
       ▼
 JWT Access Token
       │
       ▼
┌──────────────┐
│   Frontend   │
│  localStorage│
└──────┬───────┘
       │
       ▼
 Protected API Requests
```

The frontend stores the authentication token and uses it for protected API requests.

# 🎟️ Booking & Payment Flow

```text
       Browse Events
             │
             ▼
        Select Event
             │
             ▼
    Check Seat Availability
             │
             ▼
       Create Booking
             │
             ▼
     Initiate Payment
             │
             ▼
      SSLCommerz Gateway
             │
             ▼
          Payment
             │
             ▼
       Payment IPN
             │
             ▼
    Backend Validation
             │
             ▼
       Booking = PAID
             │
             ▼
   Confirmation Email
             │
             ▼
    Payment Success Page
             │
             ▼
       My Bookings
```

### Payment Integration

EventFlow integrates **SSLCommerz Sandbox** for online payment testing.

The backend:

* Creates the payment request
* Redirects users to the SSLCommerz gateway
* Receives payment callbacks
* Handles IPN requests
* Validates successful transactions
* Stores transaction IDs
* Updates booking status to `PAID`
* Sends booking confirmation email

          Mailtrap

            │
            ▼

            │

# 💻 Run Locally

## 1. Clone the repository

```bash
git clone https://github.com/raihankabir1952/event-booking.git

cd event-booking
```

---

## 2. Start Frontend

```bash
cd frontend

npm install

npm run dev
```

Frontend:

```text
http://localhost:3000
```

---

## 3. Start Backend

Open another terminal:

```bash
cd backend

npm install

npm run start:dev
```

Backend:

```text
http://localhost:4000
```
